que es una variable? una variable es simplemente una caja con etiqueta en la memoria de la computadora exactamente en la RAM.

ejemplo
doctor1="carlos_mendoza"
\\en pocas palabras es asignar un valor a algo para despues utilizarlo//

pero las variables en python tienen sus propias partes y esas partes tienen un nombre 

# la etiqueta.//(nombre de la variable)\\ es la palabra que usamos para referirnos al valor de la caja por ejemplo nombre_paciente

# el contenido //(valor)\\ es la informacion que se coloca dentro de la caja ejemplo "carlos mendoza"

porque se llama VARIABLE , porque el valor guardado en  esa caja no es fijo puede cambiar o actualizarse a medida que el programa avanza.
